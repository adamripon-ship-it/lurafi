# Mitipi / KEVIN® 3

> KEVIN® 3 ist ein Schweizer Anwesenheitssimulator (Einbruchschutz) der Mitipi AG aus Fribourg. Er lässt ein leeres Zuhause durch Licht, patentierte bewegte Schatten und über 70 Stunden Alltagsgeräusche vom 32-GB-Speicher im Gerät so aussehen und klingen, als wäre es bewohnt. Keine Kamera, kein Mikrofon, läuft auch weiter, wenn das WLAN gestört wird. {{PRICE}} einmalig, kein Abonnement.

- Produkt: KEVIN® 3 (Kevin 3, KEVIN 3.0), dritte Generation, seit 2023 im Handel.

- Preis: {{PRICE}} einmalig; optionale farbige Frontabdeckungen je {{COVER_PRICE}}. Kein Abonnement.
